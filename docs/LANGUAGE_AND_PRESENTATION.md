# Language and Presentation

The application interface is English throughout: navigation, page titles, labels, controls, notifications, chart labels and 2D/3D digital-twin controls.

The following documents are intentionally written in Hinglish for the project owner's learning and presentation preparation only:

- `PROJECT_EXPLANATION_HINGLISH.md`
- `VIDEO_OVERVIEW_SCRIPT_HINGLISH.md`

These learning documents do not affect the language of the application UI.
